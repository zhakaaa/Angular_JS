# Angular (JS/TS) Projects

This repository contains my coursework and practical assignments completed while studying **Angular (JavaScript/TypeScript)** during my university education.

## Contents

The repository includes:

* Practical assignments and exercises built with Angular.
* Projects developed using TypeScript and modern front-end development practices.
* Components, services, and modules demonstrating core Angular concepts.
* API integration examples and frontend logic implementations.
* Study materials and notes used for learning Angular framework fundamentals.

## Purpose

The purpose of this repository is to document my learning process in frontend development using Angular and TypeScript, as well as to apply theoretical knowledge in building structured, component-based web applications.

This collection reflects my progress in understanding SPA architecture, reactive programming, and modern frontend development workflows.
